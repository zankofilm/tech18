# مدرسه‌یار معلم — Android Native 3.2.0 Full Teacher

اپلیکیشن Native معلم برای مدرسه‌یار، طراحی‌شده با Jetpack Compose و Material 3 و متصل مستقیم به APIهای واقعی هاست.

## ویژگی‌های اصلی

- بدون WebView؛ همه رابط‌ها داخل Android ساخته شده‌اند.
- ورود، MFA و تغییر رمز مستقیم با API هاست.
- داشبورد حرفه‌ای Teal Pro.
- مجموعه کامل امکانات نقش معلم، گروه‌بندی‌شده برای دسترسی سریع.
- حضور و غیاب، نمرات، سؤال، آزمون، تصحیح، تکالیف، تمرین، کتابخانه، پیام‌ها، ملاقات اولیا، برنامه آموزشی، گزارش‌ها و پیگیری.
- بانک سؤال و آزمون مستقل مطابق ماژول P63.5 هاست.
- اثر انگشت: یک بار فعال‌سازی، سپس قفل خودکار هنگام هر بازگشت واقعی به برنامه؛ بدون تکرار داخل صفحات.
- ذخیره امن نشست با Android Keystore.

## مسیر سرور

به طور پیش‌فرض:

`https://scooljavanrood.ir/app/`

در Build می‌توان `WEB_APP_URL` را با Gradle property یا environment variable تغییر داد. API base همان مسیر بدون `/` پایانی است و درخواست‌ها به `/api/...` اضافه می‌شوند.

## ساخت APK

Workflow داخل `.github/workflows/build-apk.yml` برای GitHub Actions قرار دارد.
